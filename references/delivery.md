# 按SKU组织文件与交付

## 唯一正式目录

一个产品一个目录，一个印花一个SKU；四种印花建四个独立SKU文件夹。每个SKU的完整七图、可替换印花、完整标题／五点／描述文案及总览放在一起。通用图允许在每个SKU各有一份，不做跨SKU去重。正式成图直接导出到SKU目录，不再复制到variants、scene-variants、delivery或解压交付副本。

```text
产品编号-产品名称/
  A001-植物印花/
    01-主图.jpg ... 07-手持.jpg
    印花.png
    文案.txt
    总览.jpg
  A002-蝴蝶印花/
  A003-足球印花/
  A004-其他印花/
  01-主图.psd
  03-水晶贴卖点.psd
  其他需要替换印花的PSD
  工作参考/
    原始产品资料、供应商图、参考图、原始印花
  工作资料/
    listing.json
    delivery.json
    中间产物/
    预览缓存/
    生产记录及替换规格、校验日志
```

根目录直接存需要换印花的PSD，不设共用模板／templates一级文件夹，不为每个SKU复制PSD，不为编辑文字制造PSD。图位仅按需要制作PSD；其他图位保留正式成图。JPG／PNG按画质与透明需求选择，不因目录更新转码已有文件；透明印花用PNG。

一个印花有多种底板颜色时仍归同一个SKU；主配色01为同印花多色组合，其他颜色单产品素材按需要放该SKU的颜色子目录，不为底色另建顶层SKU。04内部多宫格仍是一个正式图位；交付用四宫格仅按明确请求生成。

## 中间产物与路径

原始参考放工作参考；生成候选、无印花固定底图、压力图、临时导出等确有必要时放工作资料/中间产物，并记录来源、用途、输入／输出相对路径、对应SKU／图位及版本。正式文案、印花与总览不放中间产物。定稿后不在其他位置保留整套最终图片副本；必要工作源图不等于重复交付。

不默认保存所有候选或重复大图，不默认生成ZIP。需要发送时才生成当前要求的一个包，不同时准备总包、分包及解压副本。不自动删除历史文件、失败版本或中间产物；清理、迁移旧产品另需明确授权。当前更新只影响新任务规则和工具，不移动已有图片、PSD、冻结版本或交付包。

## 固定交付工具

新任务清单放`工作资料/delivery.json`，设`project_root=".."`，图像及模板路径都相对产品根目录；允许的根目录配置只有`.`（旧默认）和`..`（上一级产品目录）。图片路径仍禁止越出选定产品根目录。新清单示例见[delivery-example.json](../assets/delivery-example.json)。

设`preview_cache_dir="工作资料/预览缓存"`，总览仍输出到SKU文件夹，机器缓存单独存放。旧清单不写这两个字段仍沿用原路径行为，不自动迁移。

```powershell
python scripts/gallery_delivery.py inspect C:/work/product/工作资料/delivery.json
python scripts/gallery_delivery.py overview C:/work/product/工作资料/delivery.json --variant A001 --out C:/work/product/A001-植物印花/总览.jpg
```

只要指定图位四宫格时，使用`grid ... --slot 07 --out <明确指定路径>`直接组合现图，不调用模型或重建PSD。`inspect --variant A001`、`overview`及`pack --variant A001`支持单SKU选择，不被其他SKU尚未完成的文件阻断。多色导出任务的清单项可有不同任务ID，但全部路径仍属于同一印花SKU。

`inspect`检查图位、图片尺寸、可读性与已声明的冻结PSD哈希；`overview`生成一份SKU总览。相同输入复用，输入或输出变化拒绝覆盖，选择新版本路径；不用临时覆盖已批准版本。

`pack`只在明确要求时执行，当前工具仅打包清单中的七图，保留原字节及扩展名、检查成员／CRC／哈希；不会自动把印花、文案、总览或PSD纳入完整SKU资料包，不把图片包称为全资料包。用户要全资料包时按实际范围另行打包并检查，仍不额外创建解压副本。

机械检查不判断图片美感、文字准确、平台适用性或真实批准。完整SKU还须确认印花.png、文案.txt、总览.jpg对应同一SKU；文案包含完整标题、五点及产品描述，不用“同上”代替。图片由生成工具完成图文，PS仅制作印花PSD；仓库贴标，不新增DIY操作图或教程视频。

## 指定范围与四款主图合并

按用户要求的实际范围建清单；一套七图加某图位四款不扩展为四套。用户要求“四款合一”且未指定图位时默认使用各SKU的01主图；明确指定其他图位时遵从指定。四合一直接合并各款已导出的完整01，不把多个印花混进单张销售主图，不用后续场景图替代。

## 轻量四合一预览

四合一默认交付压缩JPG，先把每格最长边缩到不超过1000像素，再拼接；四张方图通常输出不超过2000×2000。JPEG从quality85起按需要降低质量，仍超过2 MiB则适当缩小画布，并核对手机可读性。保留单张高清图，不把原尺寸四图直接合并为发送文件，不依赖源PNG体积估算最终JPG体积。交付时报告实际尺寸和文件大小。已有大预览不自动删除或覆盖。
