# Photoshop 母版与固定替换

## 结构由真实画面决定

- `FIXED_SCENE`：图片生成工具已完成画面、正式文字和排版的固定底图，仅产品贴附区域无旧印花；无印花不等于无文字。
- `PRINT_ARTWORK`：嵌入式智能对象，统一源画布；在母版阶段设定位置、必要的摄影透视／曲面变形和区域蒙版。
- 前景层或遮挡蒙版：用于真正跨入印花面的手指、挂带、五金等。没有交叉时不强行添加，记录依据。
- `SURFACE_LIGHTING` 或等效处理：保留真实光影，不引入首款图案。透明印花要能露出原产品底色。
- 图片文字：全部在图片生成工具中确定、生成及修正，固化在固定底图；不要求可编辑文字层，不在PS创建、修改或排版标题、正文、细节描述、尺寸数字或引线。

不要求拆分全部背景；纯通用图不必制造无用印花层。初期编辑同一母版属于设计，后续按图案重做母版属于错误路径。先在图片生成工具完成正式排版，PS只制作印花PSD，完整首套视觉审核后再冻结SHA256。

## 可印区域与无缝贴合

逐张识别真实可印区域边界，而不是套用近似矩形或椭圆。可用精细路径、矢量蒙版或高质量像素蒙版，保留可编辑结构；圆形带透视时按实际内沿校准，不假设是标准正圆。保留金属边框、弧边、五金、镜面与前景遮挡。没有制造依据时不越过已确认的平整区域。

每款声明 `coverage_mode`：满版和镂空分开处理。满版按可见内容边界适配，去除源图非设计性的透明安全边，保留主体比例，让图案以适量出血覆盖蒙版边界，再由精细蒙版裁切；不让安全边露成白圈，也不把制造上真实不可印的边误当缺陷。镂空款保持透明背景和合理构图留白，不能为了满盖而拉伸、切掉文字或扩大主体。

源画布尺寸、有效图案边界与摄影变换分别记录。统一源画布不能代替图案适配；不得用给透明画布角落添加近透明像素的方法冒充有效内容边界。固定母版冻结前确定源画布到可印区域的映射，后续仅替换规范源图。

首次带印花成图和每款实际换图均检查完整边界：先100%或更高放大检查白缝、偏心、越框、光影断层、旧图和遮挡，再看整图与手机预览。明显错误必须在交付前自行修正；允许人工少量精修不等于依赖人工补救。保存区域、路径／蒙版和必要边缘检查证据，文件／哈希通过不等于贴合通过。

## 当前固定脚本能力

使用环境报告中的PowerShell。下面的 `pwsh` 仅为命令示例，不硬编码用户机器路径。

```powershell
pwsh -NoProfile -File scripts/photoshop.ps1 -Mode Probe
pwsh -NoProfile -File scripts/photoshop.ps1 -Mode Build -SpecPath build.json
pwsh -NoProfile -File scripts/photoshop.ps1 -Mode Inspect -DocumentPath template.psd
pwsh -NoProfile -File scripts/photoshop.ps1 -Mode TrialReplace -SpecPath replace.json
```

`Build` 仅创建无印花底图加矩形位置的智能对象，不会自动识别产品区域、创建蒙版、遮挡、透视或文字版式。复杂印花模板由AI通过当前受支持的原生Photoshop代码／接口构建并真实检查；图文版式不在PS制作。不要把两层技术小样当完整产品模板。

`Inspect` 检查顶层 `PRINT_ARTWORK` 的智能对象类型、图层名与边界；它自身不完整检查蒙版／变形／字体，必要时另做原生只读检查，保存证据。

`TrialReplace` 在副本中用 `placedLayerReplaceContents` 替换已有智能对象，导出PNG后关闭副本，不保存模板。母版已有的蒙版、透视和前景可保留，实际可用范围由真实模板测试决定；不要因为Build仅矩形就把所有已验证商品模板一律说成不可用。也不能把单模板替换说成通用图库／随机抽样工具。

替换输入：

```json
{
  "template_path": "C:/work/01-主图.psd",
  "artwork_path": "C:/work/A002-蝴蝶印花/印花.png",
  "preview_path": "C:/work/A002-蝴蝶印花/01-主图.png"
}
```

候选图必须与智能对象源画布相同尺寸。图案在同尺寸源画布内等比排布；文字／透明款留安全边距，满覆盖规则单独声明，摄影平面的变换固定在母版上。1600×1600 是本次P002的已验证选择，不强制所有产品同尺寸。

脚本有输入和输出存在性检查，不覆盖已有输出，不关闭用户文档，不永久修改偏好。可由宿主按保存的规格顺序调用同一固定入口；调度清单不替代替换实现，不得临时重写换图算法来伪装固定工具验收。

## 权限与故障

沙盒内COM曾报 `0x80080005 CO_E_SERVER_EXEC_FAILURE`，正常桌面权限可连接Photoshop 26.0.0。用宿主审批机制处理，不解释成未安装；冷启动保留合理等待，不并发重复启动。旧Windows PowerShell可能因执行策略拒绝脚本，使用报告里已经可执行的PowerShell 7；不改执行策略、不用Bypass、不改注册表、不安装大型应用绕过。

仅关闭本次打开的工作副本，偏好在finally恢复；先从文档跟踪列表移除自己即将关闭的对象，再关闭，避免访问失效的Photoshop宿主对象。不要用恢复偏好的异常掩盖原始错误。保留原始错误和当前成果。

## 验收范围

按 [production-workflow.md](production-workflow.md) 记录真实蒙版、满覆盖、透明、比例、遮挡和重复导出，冻结前后哈希不变。对视觉、工具和平台分别给结论；机械通过不表示图片能卖货。P002的具体经验只放交接记录，不能把其圆形蒙版和视角泛化到其他商品。

## 多色组合与印花特写

多色主图每个产品、03水晶贴局部特写等所有可见印花都须声明智能对象／区域映射，复用同一规范印花源；每个区域单独校准位置、透视、蒙版与遮挡，换款后逐一核对不漏换。正文、底板颜色、尺寸与固定构图保持不变。

`TrialReplace`默认替换顶层`PRINT_ARTWORK`；多对象模板在规格中明确提供 `print_layer_names`（唯一且非空的顶层智能对象名称列表），同一次替换将对列表内各对象使用同一规范图案并逐项记录。`Inspect`列出顶层全部PRINT_ARTWORK对象。未声明／嵌套对象不自动遍历，不把单对象成功冒充整图完成；实际多对象成图须逐个核对。弧边不做跨边满印，贴附范围以已确认的平整区域为准。

## PSD保存位置

仅需要换印花的PSD存产品根目录，按图位命名，不建共用模板／templates一级目录，不按SKU复制母版。单印花源存对应SKU的印花.png，实际导出直接写对应SKU。TrialReplace当前导出PNG，示例沿用.png，不改扩展名冒充JPG；需要JPG时另按明确导出规格处理。固定底图和测试临时文件集中放工作资料/中间产物，记录相对路径，不改既有模板。

## 不同源图与细节图的固定替换

源像素数不同、长宽比不同先等比规范到统一源画布；满版与镂空保留各自策略，不用画布尺寸替代有效内容适配。04细节多宫格的每个可见印花面也须有独立可编辑智能对象／区域映射，固化斜视压缩、旋转或必要透视变换及画框裁切，精细蒙版保护五金、镜面、手指和标签。后续固定入口按声明对象列表同步换内容，不每款重做PSD或单独定位；实际多款验证过的范围才写为批量可用。
