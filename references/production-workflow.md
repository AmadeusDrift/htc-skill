# 先定稿母版，再快速换印花

## 两个阶段不可倒置

**设计阶段**完成第一款完整轮播图：产品事实、买家与购买理由、场景和构图、卖点证据、情绪文案、图片生成工具完成的正式图文排版、印花融合、可复用印花PSD。先修好这套图，再扩大图案数量。3–5种样式不再作为“完整视觉之前必须先暂停”的流程主线；如技术可行性确实未知，可做最小单角度探测，但它不等于母版定稿。

**生产阶段**复用已批准或明确委托完成的母版。记录版本与SHA256，仅替换印花智能对象，导出每款完整套图。禁止每种印花重做PSD、逐张调用生成模型重绘产品或改场景。

有手持场景时检查真实手指是否进入印花面：进入就建立前景层／遮挡蒙版；如果手只在外框或底部，记录无交叉的判断并以满覆盖验证。不要无意义地添加前景层，也不能以缩小图案躲开遮挡测试。

## 审核与冻结

默认提供资料、方案、第一套最终七图等有价值的确认节点；用户已批准的同版本信息不重复询问。用户明确“中间不暂停”优先，记录 `first_set_review.status=delegated`、原话依据和 `ai_visual_review=true`；这不是 `approved`。普通批准记录 `approved` 和对应成品版本。

第一套自查与审核包括购买逻辑、场景差异、构图、正式文字、可读性、卖点、尺度及产品一致性。冻结前可改同一套母版；冻结后记录哈希，所有后续换图保持它不变。用户后续只索要四宫格或打包，不使批准失效。

## 声明范围内的验收

1. 重开保存后的真实PSD，检查智能对象类型、区域蒙版、前景、透视及固定图文画面；不要求新母版有可编辑文字层，不能只看图层名字。
2. 用实际销售图案测试；按适用范围覆盖纯文字、图文、透明底与全区域压力图，再测横／竖／近方比例。缺样式只标技术测试，不擅自新增销售款。
3. 比较印花区域之外的像素；检查边框、五金、镜面、手指和固定图片文字，并核对多色组合／特写的所有印花对象，原透明处没有旧图／白方块。
4. 同一模板与图案重复导出应一致；固定PSD SHA256前后不变。记录工具入口／哈希、规格、源画布和日志。
5. 整套视觉检查与有限工具检查分开。只有上述真实证据通过才称 `verified_for_declared_templates`；这个状态不证明任意曲面、其他产品或平台政策。

矩形环境小样通过仅证明COM与基本保存替换。`photoshop.ps1 Build` 不会创建商品蒙版／透视；`TrialReplace` 可保留母版已有结构。经过真实商品验证的特定模板应明确报告可用，不必等一个无关的通用图库／独立批处理系统。但未测试的能力不能宣称支持，失败项标 `tool_validation_pending` 并具体描述。

## 进度与效率

首次母版制作含图片生成工具完成场景／图文排版及修正，再由PS制作印花PSD，耗时与冻结后的换图不同；不要把两者混称“套图慢”。记录影像调用次数、模板创建次数、替换次数和交付动作；已有素材则不重新清晰化，环境未变则复用检查，预览及压缩包未变则复用。底图是中间产物，正式成品预览优先。实际交付工具见 [delivery.md](delivery.md)。

## 文件落位

开始前声明产品目录、SKU文件夹及需要的根目录PSD路径。固定底图与必要测试／临时输出在工作资料/中间产物，原始参考在工作参考；生成日志与路径映射在工作资料。正式成图直接导出到SKU文件夹，总览也只放对应SKU；不另建scene-variants或delivery复制同一套图。既有产品只按其现有映射继续，不因新规则迁移或删除。

交付质量门槛：按真实可印边界精确制作可编辑蒙版；满版与镂空分别适配。首套及换款后放大检查完整边缘，白圈、偏位、越界、旧图和遮挡错误必须自行修正再交付，不能转嫁为必需的人工调整。通用构图按产品占比与留白动态定标题，同套统一字体风格，不套用某产品固定字号。

03按assets/uv-dtf-copy.json固定标题及五点，不再标工艺待确认。04所有可见印花面均纳入智能对象替换清单，包括侧面、斜视和被画框裁切的特写；母版阶段校准变换、蒙版、遮挡及光影，换款仅替换源内容。用实际不同印花验证两个／多个实例同步更新、不逐款手调，再声明该母版支持批量替换；不推断任意新产品也已支持。

用户更改通用视觉标准时，先同步skill与对应资料，再按新版skill执行底板→PSD印花→成图→压缩合并。03固定文案、排版按产品自由适配；用户参考是质感和层级示例，不强制分栏、产品站位或文字区。标题克制，五点手机可读。

已有批准版本仅换印花或仅改文案时保护原构图；明确要求优化03排版时，可在该图位调整，不扩大为其他图位重做。哑光／亮面对比页和小窗目前暂停，不默认新增成图或配对版本。
