# 从购买理由到完整视觉

## 先确定这套图为何能打动买家

用一段简短策略回答：谁会买、为什么喜欢这类图案、实物满足什么需要、还有哪些购买疑虑、整体应传达什么情绪。不要从“已有七个文件名”倒推内容。

每张图承担一个主要问题，下一张增加新的证据或情境。首图先让人认出实物并喜欢图案，后续把情绪、卖点、功能证据和实际尺度连接起来。不同产品可选择使用、安装、贴附、结构、场景、细节、尺寸、配套选择等内容；没有的功能不编造。七图位属于默认交付规模，不是通用内容模板。

## 方案必须落实到画面

每张记录以下信息，写到足以指导生成和原生排版：

| 项目 | 要做出的决定 |
|---|---|
| 购买问题／信息增量 | 买家看完明确知道什么；为何不能由另一张代替 |
| 构图 | 主体位置与占比、景别、视角、前中后景、留白与视觉焦点 |
| 场景 | 地点、真实用途、光线、材质、配色、道具与产品尺度关系 |
| 文案 | 情绪标题、事实说明／标签、必要数值单位、逐条中文意思 |
| 排版 | 字体角色、标题／正文／标签层级、文字区与产品轮廓、对齐和对比 |
| 实物依据 | fact_ids；图案内容不等于材质、性能、认证或附赠品 |
| 生产 | 可换区域、禁止覆盖处、前景、透视、共用范围、源图与模板编号 |

首图不额外叠字是当前项目要求，不等于平台政策已经核实；图案原有文字保留。其他图位不能以“尚未加字的底图”交最终稿。

## 情绪标题 + 具体证据

情绪文案表达买家愿意拥有它的理由；事实说明解释产品如何承接这个理由。两者不能互相替代。

例如随身镜的卖点图可以用 “A little confidence, close at hand.”，然后用实物与“7 cm、折叠结构、内部双镜面”支撑。只写这句标题会空泛；只列三个参数则缺少购买情绪。此示例仅适用于有对应事实的随身镜，不作为所有产品通用文案。

文案优先具体、自然、有生活感，避免促销、过度承诺和堆砌形容词。纯文字印花也要校对本身的拼写。主题专属文字须随图案更换，不能把首款主题烘焙到底图。

## 构图与排版验收

- 主体要清晰，实物身份、开合／结构与比例可信；不要把镜盒做成圆盘、粉饼或厚罐。
- 图案是 POD 的购买核心，不能因场景道具或标题被弱化；图案的大小按产品和样式适配。
- 标题、说明、数字／标签分层，文字与主体互相配合；大标题不压住关键结构，小字在手机尺寸预览仍可读。
- 预先给文字留位置。必要时原生设计信息区，而非每张套同一白色横条。颜色、字体和间距构成统一体系，但场景和信息组织有变化。
- 情境变化应能看见：如梳妆台、出行桌面、手持使用；不要求每个品类固定三个场景，也不能用危险／不适用场景凑丰富度。
- 细节图要揭示具体结构或印花衔接，不能仅把主图放大后换标题。尺寸图数值、单位、引线和测量对象必须对应；未知厚度或重量不编造。
- 同一正面图裁切、换横条、加一句情绪词，不构成七张有效信息。允许合理复用，但每张必须有购买价值。

## 第一套的完成条件

先选一款有代表性的印花完成**整套**。总览应显示带印花和正式文字的最终排版，必要时补大图或手机缩略检查。AI先自行修正低对比、字号过小、拼写、文字出界、遮挡或重复画面，再交用户。

用户批准后冻结；用户取消中间暂停则记录委托依据并自行执行同一质量检查，不伪造人工批准。用户说“不要再改”后仅换图／导出／打包。多印花不构成提前降低第一套标准的理由。

所有正式文字保留原生可编辑层；图像生成可先产无字底图，必须在进度说明中标清。最终图不要求七张都由模型新生成：真实摄影、已批准可复用资产和原生图形排版均可使用，但不能以占位图充数。记录原生分辨率与重采样输出，例如 1254→2000，不能称为原生2000摄影。
