# POD卷装帆布画芯Listing


## PSD 白胚审核与真实换图必读

所有包含 PSD 的新建或修订轮播，先读 [白胚审核与真实换印花验收](references/psd-review-acceptance.md)。白胚完整轮播同时附上**一张 2×2 四宫格，将透明底纯文字、透明底纯图案、透明底图文、满版图文四款的主图拼在一起**；四款须内部实套完整轮播并逐实例检查。每次轮播修订审核带上当前实套总览，未变化成果可复用。技术压力图不能替代四款真实审核印花；按实际 JSX、输入边界、满版覆盖、透视、光影及隔离迁移分别验收。仅拼已有批准图片、非 PSD 或用户明确缩小范围时按实际授权执行，不强制重做或提前交付最终 PSD。


版本1.2.0。用于本类产品的资料、Listing文案、完整图集、联动PSD母版和定稿换图。本skill资源独立；不修改或运行原pod-haul-listing，不继承其固定UV DTF03、03免建PSD或仓库贴标口径。



## PSD 母版自包含与迁移验收

每个交付的 PSD 母版必须是可独立迁移的单个文件：场景、印花智能对象及褶皱／纹理、置换、蒙版、遮挡、光影等换印花和导出所需素材与效果全部嵌入或保存在该 PSD 内，不得依赖外部辅助 PSD、链接智能对象、外部贴图、绝对路径或原电脑临时文件。中间制作文件可存在，但不能成为最终母版运行依赖；不同规格或模板族按原规则分别交付独立 PSD，不要求所有规格合并成一个文件。新印花输入、明确交付的 JSX 工具及运行环境不属于母版内嵌素材；脚本不得硬编码原电脑路径或依赖未交付辅助文件。

交付前将最终 PSD 单独复制到隔离目录，使原素材和辅助文件不可访问，在 Photoshop 中重新打开，检查所有嵌套智能对象无缺失或外链；使用交付的实际 JSX 或指定换图入口，输入一张测试印花，执行完整替换和导出，检查所有实例、褶皱／遮挡效果与导出结果，再重新打开确认。尽可能在另一台电脑测试；未实测另一台时只报告隔离目录测试结果，不声称跨电脑已验证。任何缺失链接、脚本路径错误或效果丢失均须修复后重测；无法完成实测则明确标记未验证，不称可独立交付。已有 PSD 不因新规则自动返工；用户要求修复时另存并验证。

## 联动PSD、印花适配与工作台接口

新建模板及批量换图先读[统一联动流程](references/shared-mockup.md)及[产品接口配置](assets/workbench-profile.json)。每个确定的模板族集中为一份共享母稿、多场景PSD，图数从产品及manifest读取；逐图声明印花实例，固定图为0。先完成真实边界、孔洞/挂件/前景等保护，再换图生产，不能因技术接口统一而改变产品口径。

调用链为Inspect → 模板manifest → 印花文件夹生成batch配置 → Export → 报告/视觉验收。保留源图，统一像素和母稿实际PPI；完整画面cover/contain与透明图案alpha+contain分别配置。不为容错主动内缩露底，不跨真实不可印边；重点主体/文字的裁切先检查。手动单张预览另有入口，不把它当文件夹批量导出界面。

五个skill自带同版本运行工具，接口一致且可独立使用；产品规则和素材仍各自独立。资料准备/文件校验可并行，同一PS的自动制作/检查/导出使用统一互斥入口串行处理。进度、失败和取消输出结构化记录，工作台后续直接调用，不另写贴图算法。本轮不自动创建工作台或改写历史商品PSD。

下文旧单图PSD、旧清单/校验器用于其已声明支持的历史模式；新建联动模式遵循统一流程，不混用通过结论。完整Listing仍按原要求交文案、原稿和总览，不能把纯PNG批次称作完整Listing交付。

## 已确认产品口径
销售物为卷装帆布／油画布画芯，不含外框、内绷框、挂轴。不能把卷装画芯画成已绷框厚画板。默认三个独立规格各交一套七图：60×30、100×38 cm横版及30×30 cm正方形；三个独立PSD，不混为一套。

尺寸与事实以[产品档案](assets/product-profile.json)为默认来源，具体产品阅读[产品规则与参考](references/product-rules.md)。用户本次明确变更高于默认，不反向修改旧图/PSD或其他产品。已确认信息不重复询问；缺项只阻塞有关图位。

05每套只标本套宽、高，保留横版方向；没有厚度参数不估算或阻塞二维尺寸图。100×38与60×30长宽比不同，分别建立源画布与PSD映射，不直接拉伸同一母版。

04优先展示画布织纹、印制表面与真实边缘，避免把卷曲截面误画成厚板。06可展示展开画芯和卷装收纳／交付情境；包装筒、保护袋等仅在产品资料有依据时展示为随货物。装裱展示若使用道具须明确不包含，优先选择不混淆销售物的无框画芯场景。

## 图位与交付规模
默认每套7张，完整图位如下。只有用户明确改变范围才调整，不能因缺图减套或减张。

| 图位 | 职责 | 关键要求 |
|---|---|---|
| 01 | 场景主图 | 清楚展示实际销售物与当前印花，无额外叠字 |
| 02 | 产品卖点 | 结构、材质优势和已确认功能，不能用图案推导性能 |
| 03 | 产品印制／工艺 | 按对应产品资料展示印制效果与工艺证据，不调用原水晶贴四路素材 |
| 04 | 产品细节 | 单特写或一张多宫格，每格配简洁说明，所有可见印花可换 |
| 05 | 尺寸 | 按本产品尺寸规则，真实引线及cm/in双单位 |
| 06 | 使用场景 | 与01区分，展示真实悬挂／展开／使用情境 |
| 07 | 质感与尺度 | 心形可手持，大画芯／挂画用可信人物或环境尺度 |

03和08若展示当前SKU印花，均须纳入PSD同步替换；纯通用无印花图可复用。不得把原skill中03免建PSD的例外带入本skill。供应商图案仅作结构参考，实际用用户提供/授权的印花。

## 按阶段执行
1. 新产品：读[生产与审核](references/production-workflow.md)，整理事实、印花和买家购买理由；用[文案规则](references/copy-and-policy.md)给出中文资料、固定产品名称加可变印花前缀的英文标题、五点及描述。固定名称默认`Unframed Canvas Print`。
2. 首套：图片生成工具完成场景、正式文字与排版，可印区无旧图案；再读[PSD与固定替换](references/simple-psd.md)及共享母稿参考，PS只制作联动智能对象、蒙版、透视、遮挡、光影，不制作可编辑文案层。每规格完成一份七场景PSD和整套导出后，展示总览、自查并审核。没有指定销售印花时仍提供白胚及四类真实审核样稿的主图四宫格；技术验收图仅作补充，审核样稿不伪装为销售定稿。
3. 冻结生产：记录首套版本、真实审核/委托依据和PSD SHA256。三个规格为独立母版族，分别为2:1、100:38和1:1。完整画面优先等比铺满；重要文字/主体可能被裁时检查具体构图，需要完整保留时显式contain，不延展、重绘或拉伸。 后续按固定入口仅换源内容，保持图文场景和母版哈希不变，不逐款重生场景或重建PSD。
4. 交付：按[目录与交付](references/delivery.md)放完整成图、适用PSD、印花、文案、总览；资料按[数据契约](references/data-contract.md)管理。联动模式按统一接口检查manifest、原生替换、图数、覆盖及哈希；旧模式仍使用原plan/files清单校验。完成独立视觉验收，不把结构检查当成商品通过。

已有批准母版只换图时复用版本与映射；只要总览/打包时直接组合已有图，不生图、不重开PS。用户要求不要再改时冻结，仅执行授权输出；取消中间暂停时记录delegated与原话，不伪造approved。默认不ZIP、不新增视频、不发布店铺、不迁移历史成果。

## 工具边界
本地scripts内photoshop.ps1、psd_smoke.py、check_environment.py、gallery_delivery.py来自原流程的独立副本。Build仅矩形小样，真实产品蒙版/透视需制作并验证；TrialReplace多实例用明确print_layer_names，不自动遍历嵌套对象。validate_project.py读取本skill档案，区分7/8图、规格组和PSD范围，不使用原validate.py。机械通过不等于视觉、真实替换或平台通过。

全程代码/接口/文件操作，不使用Computer Use。COM权限按宿主审批处理，不改执行策略或注册表，不关闭用户文档。环境检查及产品测试产物写产品工作资料，避免写入技能或原skill。只报告实际验证的模板范围。
