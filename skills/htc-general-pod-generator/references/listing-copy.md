# Listing 文案与轮播、PSD 同步流程

## 适用范围与交付

新产品完整轮播和可替换印花 PSD 母版制作，默认包含产品标题模板、五点描述、完整产品描述。三项从规划阶段同步编写，白胚/首套审核同步展示，最终 PSD 交付时一并提供独立可复制文案文件，不等运营另提要求。只做完整预览时按本次阶段交付文案，不强制提前交付 PSD。

已有批准母版只换印花、做总览或局部改图，复用已批准且适用的通用文案；不因新规则自动重做、重写或补做历史成果。若本次交付 PSD，随附或明确引用可访问的同版文案，并在 Codex 最终聊天回复中逐条展示该版五点正文。旧文案缺失则列明缺项，按本次授权补齐，不冒称完整。用户明确只做图片、PSD 或缩小范围时，以用户要求为准。

## 同步制作顺序

1. **产品事实表。** 从实拍、供应商资料和用户确认提取「事实｜证据来源｜适用产品/颜色/规格｜可用表述｜待确认项」。区分实物结构与印花造成的视觉效果。照片可证明可见结构，不能证明耐用、防水、无毒等性能。图片、上图文字和 Listing 共用这张表。
2. **文案与图位并行。** 先写标题模板、五点和描述初稿，再把有依据的卖点安排到图位；可迭代调整，但不先做完七图和 PSD 再临时补 Listing。文案正文和内部事实/缺项记录分开。
3. **首套同步审核。** 随白胚/首套预览附文案初稿，检查产品命名、结构、尺寸、数量、用途与画面一致。实物结构、配件或规格有变动时同步修订受影响文案和图片，不新增等待批准关卡，沿用既有用户批准或委托方式。
4. **换印花复用。** 同一产品型号、结构和规格下，仅替换标题中的印花关键词；五点、描述和固定图上文案保持通用。不同尺寸、材质、配件或结构需分组，不能把仅适用于某款的事实写成全系列共用。
5. **随 PSD 交付定稿。** 文案文件包含产品/规格标识、适用变体、版本、目标语言、标题模板、Bullet 1–5、Product Description。默认使用目标语言，可附中文核对说明；用户指定表格或文件格式时遵循要求，否则使用独立 UTF-8 文本文件。最终交付时，在 Codex 聊天回复正文中用 1–5 的编号列表逐条贴出目标语言的五点完整正文，顺序和措辞须与同版文案文件一致，方便直接复制。独立文案文件仍须交付，文件链接或摘要不能替代回复里的五点正文。不将内部待确认注释混入可发布字段。

## 标题：描述产品，预留印花位置

默认结构：**`[有依据的产品属性 + 核心品类 + 必要用途], {关键词} [自然且不重复的补充短语]`**。`{关键词}` 专门预留给 POD 印花主题/图案名称，不是材质、功能、受众或泛搜索词列表。每个产品交付一个主模板，默认一个占位，位置可按自然语序和用户已定格式调整。补充短语没有信息增量时省略；不为凑满结构而堆词。

- 图1一类旧标题只参考固定产品段与占位段的组织方式，不沿用其品类重复。先让买家知道具体是什么产品，优先保留能区分该款的真实形态、结构、材料或用途；不是所有属性都要塞进标题。
- 避免同一品类机械重复，如 `Bottle Opener … Bottle Opener`、`T-Shirt … Shirt`、`Keychain … Key Ring`；按实物选择准确主称呼，不用同义词轮换堆砌。`Pill Organizer Box` 等有自然语义的组合按上下文判断，不机械按禁词表删除。
- 占位应能填入 `Highland Cow` 等简短印花词组后自然成句；模板交付保留占位，不擅自替换成当前审核样稿主题。仅在用户要求实际 SKU 标题时填入，并检查重复、语法和字符数。
- 已确认的本产品标题沿用：`Vintage Wall Art & Tabletop Display, {关键词} Home Decor`。关键词与此前 `{图案名称}` 同义。此例仅适用于已确认的该产品，不把 Vintage、壁挂或桌面摆放推广到其他产品。标题不出现 Faux/Faux Framed，也不改成声称实物真画框的 Framed；五点与描述仍须准确说明已确认的真实结构，不能隐瞒会影响购买判断的产品事实。
- 其他产品结构示例（属性均须有依据）：`Round Magnetic Beer Bottle Opener, {关键词}`。不复制旧版重复开瓶器称谓，也不为了加关键词重复品类。
- 截图/第三方建议不是事实或平台政策依据。不自动将印花强制放到最前，不把逗号前后位置解释为已证实的搜索权重，也不承诺“算法冲突”。
- 用户要求字符目标时按该目标预留关键词空间，给出固定段字符数和剩余预算；填入实际关键词后重新计算。未定目标时以准确、自然、简洁为准。75–80 字符不是本 skill 的统一平台上限；平台/类目规则影响输出时查证当前官方规则并记录来源及日期，不在未核实时声称平台合规已验证。

## 五点：同款产品共用，恰好五条

面向买家解释产品本身，每条一个主要购买信息，用具体产品事实说明用途或使用价值。各条可用简短功能标题加自然句子；不是五个关键词串，也不是七张图的标题清单。

按该产品证据选择五个不同角度，例如真实结构/形态、已确认材料与表面、操作/使用方式、尺寸/收纳/摆放、包装数量/配件/护理限制。此列表是选题池，非固定分工；没有证据的角度换成其他有依据的信息，不为凑五条编造。资料确实不足以支持五条独立信息时，交付有依据草稿并在正文外列缺项，标记未定稿，不用同义改写凑数或把四条冒称五点完成。

五点不出现单款动物、花卉、文字内容、印花颜色/风格、节日主题、图案故事、特定爱好者送礼场景，不留印花占位，也不因四款审核样稿分别写四套。可在确有必要时中性说明产品有印花装饰，不承诺定制服务、任意设计可选、双面印刷或未确认工艺。

## 产品描述：独立完整的通用正文

使用自然连贯段落说明这是什么产品、真实结构与实际使用方法，结合已确认的规格、包含物和必要限制回答购买问题。不能只粘贴五点、输出一句泛泛宣传或重复标题；也不引入五点和资料中没有依据的新性能。正文同样不依赖某个印花主题，替换成任意其他适用印花后仍须成立。

不自行增加“高品质、耐用、防水、防刮、抗菌、无毒、食品级、BPA-free、环保、适用所有型号、儿童安全、可机洗”等声明；性能、认证、兼容性、护理和保修承诺必须有相应证据。药盒描述聚焦分隔和收纳，不延伸到疗效、用药安全保证或防潮/儿童锁承诺。已知重要限制应准确说明，未知项不反向编成负面断言。

## 交付前逐项验收

| 检查项 | 通过条件 |
| --- | --- |
| 三项齐全 | 一个主标题模板、恰好五条有不同信息的要点、独立完整产品描述；草稿/缺项不标定稿 |
| 聊天展示 | PSD 交付的 Codex 最终回复包含 1–5 条完整五点正文，逐条核对顺序和措辞与同版文案一致。资料不足时明确标记草稿及缺项。 |
| 标题可替换 | 印花占位含义和位置明确；试填两种不同主题检查自然语序与去重，交付仍保留占位；实际 SKU 输出检查填词后长度 |
| 通用性 | 将当前印花换成不相干主题，五点、描述和固定图文仍准确；不得把审核样稿当系列事实 |
| 产品具体性 | 能识别真实品类、结构、用途，而非适用任何产品的漂亮、时尚、送礼等空话 |
| 事实与变体 | 每项实质声明可追溯证据，适用于标注的全部变体；数量/配件/尺寸/单位/颜色与图和 PSD 一致 |
| 范围与状态 | 新套同步交付，旧批准套按授权复用；文件版本可对应，待确认项与可发布正文分开 |
| 平台规则 | 按适用平台与类目核实；没有平台或未核实则记录审核范围，不承诺平台审核通过 |

文案审核与视觉、真实换印花、隔离迁移分别记录。任一未完成都不能被其他通过项抵消。
