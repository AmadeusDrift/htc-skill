# HTC 通用 POD 生成

独立 skill，按不同产品的实际形态和用户范围规划 POD 图文，使用随附的共享 PSD 运行工具制作联动母版与批量换图。入口见 [SKILL.md](SKILL.md)，PSD 流程见 [shared-mockup.md](references/shared-mockup.md)。

共享运行工具来源于 `AmadeusDrift/htc-skill` 提交 `da8cdefafb21a1090107a9d3ca4026d08f8e4fa5` 的 `pod-haul-listing`，版本和文件哈希见 `assets/runtime-manifest.json`。随附 MIT 许可。实际商品结构、曲面、模板与 Photoshop 输出须另行验证；运行工具历史记录的七、八图验证不等于所有图数和产品均已实测。
