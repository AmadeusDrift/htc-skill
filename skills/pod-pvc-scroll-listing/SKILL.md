# POD PVC挂轴画Listing

版本1.0.0。用于本类产品的资料、Listing文案、完整图集、印花PSD母版和定稿换图。沿用pod-haul-listing 0.9.0的成熟流程，本skill资源独立；不修改或运行原skill，不继承其固定UV DTF03、03免建PSD或仓库贴标口径。

## 已确认产品口径
销售物为PVC挂轴结构加油画布画芯的挂画。PVC描述挂轴，不把画芯改写成PVC片材，也不画成实木挂条或四边框。只选20×30、30×45、40×60 cm，排除供应商25×37.5 cm等未选规格，共一套八图。

尺寸与事实以[产品档案](assets/product-profile.json)为默认来源，具体产品阅读[产品规则与参考](references/product-rules.md)。用户本次明确变更高于默认，不反向修改旧图/PSD或其他产品。已确认信息不重复询问；缺项只阻塞有关图位。

05同张展示20×30、30×45、40×60 cm，真实比例比较并同时标厘米／英寸。当前只确认宽、高，不估算轴径／厚度或含绳总高，也不因这些缺项阻塞二维尺寸图；用户明确要求新增参数时另取证。

04展示对应产品的PVC上下轴、端部、挂绳及画布连接结构；不要借用实木挂画的五金或磁吸结构。包装和装配方法可参考对应供应商图，但不凭空增加赠品或免钉承诺。08必须额外说明油画布画芯及确认的材质卖点，不能替代03印制说明。

## 图位与交付规模
默认每套8张，完整图位如下。只有用户明确改变范围才调整，不能因缺图减套或减张。

| 图位 | 职责 | 关键要求 |
|---|---|---|
| 01 | 场景主图 | 清楚展示实际销售物与当前印花，无额外叠字 |
| 02 | 产品卖点 | 结构、材质优势和已确认功能，不能用图案推导性能 |
| 03 | 产品印制／工艺 | 按对应产品资料展示印制效果与工艺证据，不调用原水晶贴四路素材 |
| 04 | 产品细节 | 单特写或一张多宫格，每格配简洁说明，所有可见印花可换 |
| 05 | 尺寸 | 按本产品尺寸规则，真实引线及cm/in双单位 |
| 06 | 使用场景 | 与01区分，展示真实悬挂／展开／使用情境 |
| 07 | 质感与尺度 | 心形可手持，大画芯／挂画用可信人物或环境尺度 |
| 08 | 额外画芯说明 | 油画布纹理与确认材质卖点；是新增一张，不占用前七张 |

03和08若展示当前SKU印花，均须纳入PSD同步替换；纯通用无印花图可复用。不得把原skill中03免建PSD的例外带入本skill。供应商图案仅作结构参考，实际用用户提供/授权的印花。

## 按阶段执行
1. 新产品：读[生产与审核](references/production-workflow.md)，整理事实、印花和买家购买理由；用[文案规则](references/copy-and-policy.md)给出中文资料、固定产品名称加可变印花前缀的英文标题、五点及描述。固定名称默认`Canvas Wall Hanging with PVC Hangers`。
2. 首套：图片生成工具完成场景、正式文字与排版，可印区无旧图案；再读[PSD与固定替换](references/simple-psd.md)，PS只制作印花智能对象、蒙版、透视、遮挡、光影，不制作可编辑文案层。完成本套全部带印花成图及适用PSD后，展示总览、自查并审核。
3. 冻结生产：记录首套版本、真实审核/委托依据和PSD SHA256。三规格均为2:3。每个可见印花面记录独立智能对象／变换／蒙版，保护PVC上下轴、端部、挂绳及夹持边界；尺寸图多产品和08中若有当前SKU印花，都同步替换。 后续按固定入口仅换源内容，保持图文场景和母版哈希不变，不逐款重生场景或重建PSD。
4. 交付：按[目录与交付](references/delivery.md)放完整成图、适用PSD、印花、文案、总览；资料按[数据契约](references/data-contract.md)管理。先plan检查，实际成品齐备后files检查，并完成独立视觉及真实PS替换验收。

已有批准母版只换图时复用版本与映射；只要总览/打包时直接组合已有图，不生图、不重开PS。用户要求不要再改时冻结，仅执行授权输出；取消中间暂停时记录delegated与原话，不伪造approved。默认不ZIP、不新增视频、不发布店铺、不迁移历史成果。

## 工具边界
本地scripts内photoshop.ps1、psd_smoke.py、check_environment.py、gallery_delivery.py来自原流程的独立副本。Build仅矩形小样，真实产品蒙版/透视需制作并验证；TrialReplace多实例用明确print_layer_names，不自动遍历嵌套对象。validate_project.py读取本skill档案，区分7/8图、规格组和PSD范围，不使用原validate.py。机械通过不等于视觉、真实替换或平台通过。

全程代码/接口/文件操作，不使用Computer Use。COM权限按宿主审批处理，不改执行策略或注册表，不关闭用户文档。环境检查及产品测试产物写产品工作资料，避免写入技能或原skill。只报告实际验证的模板范围。
