# HTC POD T-Shirt

根据真实 T 恤资料与印花制作独立商品图、总览及可替换印花 PSD。适用于新建、季节版改日常版、换图、单图修订；其他产品使用其专用 skill。

## 先确定范围与事实

- 先读已有成图、PSD、使用说明及用户指定参考。用户说“参考圣诞款材质/版型”时，实际查看对应单图；保留其被认可的结构，按授权修改。
- 区分当前产品事实、视觉参考、示例印花、未来可售组合。颜色、成分、工艺、尺码与印区只采用已确认资料；示例图中的暖白、黑色、牛奶丝或棉涤比例都不是所有 T 恤的默认事实。
- 新资料与旧稿冲突时仅确认影响本次工作的部分；确认后同步改相关图、文案与模板。报价的售卖范围和尺码表的覆盖范围分别记录，不能据此编造库存。
- 明确渠道、语言、图数、画幅和交付阶段。HTC 低价商城项目可按用户确认采用**无叠加文案的场景主图**；不能仅因出现“亚马逊”就改成普通站点白底方案。用户项目规则与已核实的平台规则分开，未核实不声称合规。
- 用户已说“先印区示意与预览，确认后再做 PSD”时保持该边界；先完整交付可审核预览。用户后来明确索要样机/PSD，才进入相应制作。不要重复索取已有授权。
- 新资料、私有报价、成图与 PSD 保留在项目，制作/分享 skill 不自动授权上传这些资料。

## 规划与首套预览

先按 [轮播与场景](references/gallery.md) 为每个图位记录：信息任务、地点与使用方式、色调和光线、机位/距离、动作、头部方向/视线、表情、文字层级、可见印花实例数。

常见八图顺序可参考：主图 → 材质 → 版型 → 居家 → 通勤 → 工作 → 周末 → 尺寸。**这是可调整方案，不是固定八图规则。** 图数、顺序、男女款及季节均以当前任务为准。

- 正式轮播预览逐张生成、逐张检查并交付独立图片；四宫格分镜或总览只能辅助审核，不能代替独立轮播图。
- 首套默认所有图位有与用途匹配的真实环境；主图若有明确渠道/用户白底要求则例外。整套按范围覆盖至少三个明显不同地点/情境，同时改变镜头、构图、色温与明暗，不能只换背景道具。
- 不仅换身体动作：头部方向、视线、表情也须有可见差异。不要每张都侧头、同一方向看镜外并微笑；不强制所有人物都笑。人物与衣服在合理姿态下保持一致，前胸印花辨识度不能被道具、包带、手臂或排版牺牲。
- 主图不叠标题、小点、徽章等附加文案；衣服本身的印花文字不是叠加广告。副图使用清晰的“标题 + 较小信息点/细节标签”，文案提供事实或搭配信息，避免一套都是空泛口号。
- “比第一版缩小 25%”指被指定基准的约 **75%**，不是把后一版继续缩小，也不是标题变成角落小字。记录基准；生成文字大小只是视觉目标，须实际检查可读性。
- 常用 3:4，但沿用已确认比例与真实像素；生成得到的像素不冒称更高分辨率。产品文字、尺寸与正式版式由图像生成工具完成；PS 用于样机、映射、遮挡和光影，不用 PS 补字掩盖错误生成。

## 共用图与印花适配

- 通用材质图通过近距离展示布料褶皱和纹理，保留生活环境。材质名称/成分按已确认事实写，不推导透气、弹力、耐洗、克重单位或性能。
- 通用版型图通常**一张内**完成领口主体 + 袖口、下摆细节；用户指定参考时沿用其结构，不擅自改为人物上身大图或拆成多个图位。
- 两种共用细节图通过角度、距离和裁切避开可印区域；不能把整件商品擦成无印花白胚再充当通用商品展示。供 PSD 使用的清洁底图与面向买家的通用细节图是不同产物。
- 尺寸图可用无印花平铺服装作为测量示意，按批准方案记录为固定图；尺码数据缺失则预留明确空位，不能填示例数字冒充实值。
- 有可见 SKU 印花的图位全部接入替换；真正不含可见印花的共用图显式记 0。五个场景印花只是常见八图方案的实例，实际数量据图统计。
- “共用”分为事实共用和场景适配：材质/版型/尺码可能共用，但一套简约文艺场景不能承诺适配所有高饱和、街头、卡通、文字印花。先看选定的真实图案，必要时建立多个场景模板族。不能擅自修改正式印花颜色、删元素来迁就场景；示例须明确标记。

## 尺码与局部修订

制作或修改尺寸图前读 [资料与尺码](references/facts-and-sizing.md)。

用户只改尺寸、标题、图位顺序、总览或印花时，仅修改对应范围；批准的其他图片、映射与固定内容保护。新尺码表不能继续携带旧的额外尺码、公差或未经确认的换算。单独 PNG 完成不等于 PSD 已同步；原生 PS 失败时分别报告真实状态。

只要总览：按已有图序排列、等比缩放、加外部审核标签即可，不重新生成场景。修改顺序应同时更新独立文件编号、实例声明与总览，保留旧版，不错混版本。

## Photoshop 样机

制作/修复样机前读 [PSD 母稿与验证](references/psd-mockup.md)。采用本机 Photoshop 原生脚本、PowerShell 与可用 Python/图像检查库；本流程默认不使用 Computer Use，用户禁止时不得转用。COM 忙/失败按运行工具提示有限重试，不强杀 PS、不关闭或保存用户其他文档，不绕过权限审批。

关键约束：

1. 根级隐藏嵌入式智能对象“母稿”必须是支持分层保存的 **PSD/PSB**。PNG 可以作为新图案导入母稿，不能作为需要新增图层后 Ctrl+S 的根级母稿容器。
2. 所有场景印花实例由同一母稿复制、保留共享对象 ID；同名独立置入不是联动。单源母版不自动支持正背两套独立图案。
3. 以实际母稿画布像素/PPI 和完整画布变换定位。透明可见内容 bounds 不是画布 bounds，不得因留白而把图案放大。
4. 按衣服透视、褶皱和真实遮挡制作映射、蒙版与光影；不要整体歪转图案模拟褶皱。黑衣浅色/彩色印花不要一律正片叠底到不可见；融合方式需看真实效果。
5. 实际验证“打开母稿 → 新增/置入新图层 → 原生保存（等同 Ctrl+S）→ 返回主样机 → 重开仍保留图层”，确认所有印花图位同步、固定图不变、母稿仍是 PSD/PSB。
6. Inspect → manifest → plan → Export → 交付检查；登记实际尺寸、PPI、实例和哈希。代表性满版边界、透明留白、横向比例按真实模板测试，不能把局部测试说成完整套数。
7. 技术通过不等于商品视觉、实物或平台验收；批准后才冻结版本和哈希。修订另存，不拿旧报告冒充新版本验证。

## 交付口径

区分独立成图、示意/总览、清洁底图、真实联动 PSD、已完成导出、已验证范围、仍待确认项。PSD 必须给到实际可打开的文件与简短换图方法；失败保留产物和原因，不把预览 PNG、技术小样或准备好的脚本称为完成样机。未要求时不额外打包。

新建/修订此 skill 后，用 [回归场景](tests/scenarios.md) 做行为检验；它不要求普通商品制作时重复读取测试文件。
