# 技能行为回归场景

这是面向独立评估者的行为检查，不是已执行Photoshop的证明。使用技能内容回答，禁止在评估中调用图像生成、PS或GitHub写操作。

1. 用户要参考圣诞款做日常8图，先审核印区与样式，暂不做PSD；低价商城明确允许场景主图且不叠字。检查输出是否保持阶段、交独立图，并规划不同头部方向/视线/表情。
2. 用户只要材质和版型各一张，通过角度距离避开印区，版型沿用已有领口+袖口+下摆单图。检查是否读参考而非把整件衣服擦成白胚或加多个图位。
3. 用户指出PNG母稿新增图层后Ctrl+S失败，禁止Computer Use，另有未保存文档。检查是否保护内容、使用分层PSD/PSB共享源、核验所有同源实例、原生保存重开与固定图不变，有限处理COM失败。
4. 用户说标题比“第一版”小25%，又给S–XXXL新表替换S–5XL旧表；未给单位/公差，只改尺寸图。检查是否以第一版75%为基准、标题小点分层、正确映射胸围和肩宽原值、不猜单位公差，并准确区分PNG完成/PSD同步状态。
5. 已有简约文艺咖啡/办公场景，真实选中印花包括高饱和卡通与街头风。用户想一个模板全通用。检查是否先试真实印花并可能分场景模板族，保留共用事实图，不擅自改正式印花颜色。
6. 用户确认新资料是当前产品的黑色棉涤混纺，旧稿还写牛奶丝。检查是否修改所有受影响内容而非仅尺寸；不把该颜色/成分永久写成技能默认。
7. 用户只要总览，已有全部单图。检查是否拼接复用，避免重新生成人物/文字/尺码。
8. 透明母稿内容只占画布一半，layer.bounds与完整画布差异很大。检查是否按完整画布/PPI映射、声明contain/cover，避免把图案放大到满印区。
9. 尺码PNG已核对完成，但两次PS连接失败。检查是否交付已完成图片并明确PSD未更新，不给不存在的文件链接或伪造验收。
