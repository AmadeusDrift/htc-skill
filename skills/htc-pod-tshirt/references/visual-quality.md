# 场景、景深与可替换性验收

## 画幅与文字

默认新建T恤场景建议3:4竖版；已批准比例和用户指定优先。1800×2400等只是制作建议，不是平台唯一法定尺寸；真实输出像素写入清单，不能声称插值恢复了细节。方图改竖图应重构或扩展场景并重查印花映射，不拉伸人物、衣服和文字。

主图无附加标题、小点、尺寸、促销徽章；服装实际印花中的文字保留。副图产品优先，标题、简短信息点与标注分层，避免大标题占据视觉中心，也不缩成难读小字。字号按画幅和手机显示检查；“比指定基准小25%”为该基准75%，不连续递减。尺寸数字、单位、英文拼写逐格放大核对。

## 多场景、多角度、多pose

整套对照地点、远近、机位、身体动作、头部方向、视线和表情逐项检查，至少出现可见差异，不能所有图同角度侧头微笑。可复用同一人物身份以保持一致；服装款式、领口、袖长、颜色和印区不能随着姿势漂移。自然站立、坐姿交流、整理装饰、迈步等均可，手、头发、包带、道具不遮关键印花。

行走不是必须的图位；若有，优先让腿部体现迈步、上身适度朝向镜头。胸口约20–30度以内可作为起点，不能当所有人物的硬性角度标准。侧身过大、扭胸、深折叠或遮挡会增加换图成本，应先调整姿势。胸前透视必须由当地衣服表面决定，不能把整张图案简单旋转成斜贴纸；文字基线、圆形、宽图案都须试放。

## 前后景深

先确定焦平面和真实距离：服装主体、印花和必要细节清楚；近前景可柔化，远后景自然虚化。材料微距允许浅景深，但用于证明纹理的区域必须清晰；信息层文字不随背景虚化。

逐张检查人物左侧与右侧后景：同距离的柱子、树枝、灯饰、门框应有合理相近的清晰度；不同距离允许不同，不为了“左右一样”机械模糊全图。不得一侧远景锐利、另一侧同距离糊成光斑。检查人物边缘光晕、衣领/皮肤上的模糊溢出、虚假径向模糊和遮挡断层。强景深是距离关系可信，不只是增加模糊量。行走图要在最终贴图之后再次看胸口和两侧后景。

## 从白胚到底图再到印花

适用于可换印花场景：先生成无图案、无旧字残留的服装清洁底图，检查版型/景深/遮挡，再通过PS映射正式或明确标记的示例印花，输出审核图。先把成品图案直接生在衣服上，再盖一个智能对象，不能算可靠白胚样机；不得拿烘焙印花冒充联动层。

预览阶段可以使用临时映射副本，不等于完整PSD已交付；遵守用户“先看图后PSD”的阶段。已有批准底图直接复用；用户仅改某张不重做全套。共用材质/结构图依自然裁切避印区，尺寸平铺示意依批准方案；清洁白胚是工作资产，不自动替代买家最终商品图。工作白胚按颜色准确呈现，也可以是黑衣，白胚不是强制白色。

## 常见错误和修正

| 错误理由 | 必须做的检查 |
|---|---|
| 节日氛围强就够了 | 检查材质、结构、图案和尺寸的信息覆盖 |
| 模特侧身更自然，印花随便斜一下 | 调整胸前可视角度，再按衣服透视/褶皱映射 |
| 加更重模糊就有景深 | 按物体实际距离核对两侧后景和焦平面 |
| 主图无字意味着删掉印花内文字 | 只去除附加广告排版，保护正式图案 |
| 白胚图片已经是最终成品 | 区分工作底图、叠印预览和真实联动PSD |
| 看见白边直接放大裁掉 | 先查底图坐标、缩放、覆盖范围及四边，再最小修复 |

逐张视觉验收在最终贴图后进行；技术导出成功或提示词写了这些要求，不能代替实际看图。
