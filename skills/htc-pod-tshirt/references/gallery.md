# 轮播、人物与图案匹配

先按[通用／节日路线](routes.md)确定主题与主图用途；人物动作、3:4改版和景深的逐图验收见[视觉质量](visual-quality.md)。

## 规划表

每张先记录以下字段再生成，不以同一机位轮流换背景替代设计：

| 字段 | 要解决的问题 |
|---|---|
| 路线/主题/用途 | general或holiday，实际节日，scene-hero或platform-main |
| 信息任务 | 主图、材质、结构、穿搭、图案、尺寸各增加什么信息 |
| 地点/行为 | 居家阅读、街道通勤、休闲办公、河畔休息等是否确实不同 |
| 镜头/构图 | 近景/中景/全身、平视/低机位/俯视、人物占比及偏左/偏右 |
| 头部/视线/表情 | 正视、低头、左右方向、闭眼休息、专注、中性、交谈发笑的差异 |
| 色调/光线 | 灰绿漫射、蓝灰清晨、赤陶工作室、深木色侧光等，衣服颜色保持真实 |
| 印花实例/遮挡 | 每个可见实例的区域、比例、视角；手、书、包带是否挡住重要内容 |
| 标题/小点 | 标题承担主题，小点增加事实/搭配信息；排版避开脸和印花 |

这些是可选构图手段，不要强制所有项目使用同一男模、年龄、场景、姿态或文案。可以合理复用人物以保证产品一致性，但不能复用同一个表情和头部方向。

## 主图和渠道

先辨认实际渠道和类目。低价商城或用户明确确认可用场景时，按该项目无附加文字的场景主图制作；不要仅根据“亚马逊”字样把整套改成普通站点白底。若目标渠道要求白底，按确认后的要求单独制作，别宣称场景图已通过该要求。未知规则影响交付时核实当前规则；不可把用户提供的例图当平台官方依据。

附加标题、卖点、尺寸、色卡、徽章与印花内的文字分别判断。无叠字主图仍可展示衣服实际印花文字。单色商品单件展示；多色只有真实可售对应表明确时才组合，不自行增加颜色，不暗示多件装。

## 通用图

- 材质图：布料自然起伏的近拍，真实窗边/穿衣区环境；以已确认材质命名，不从画面推断成分。若用户说参考已有材质图，直接读取该图，沿用被认可的褶皱、视距和构图。
- 版型图：领口主体，袖口与下摆局部窗口可以融合在同一张商品图内。窗口不是额外交付图位。不要在用户已经选定该结构后换成大幅上身照。
- 共用细节取景应自然避开胸前印区，而非拿有印花商品的整件白胚照片作“通用展示”。原生样机制作需要的无印花底图是工作资产，不混淆两者。
- 尺寸图：真实使用环境中服装平铺完整，信息区清楚。数据未齐允许留空，但只交付占位设计，不能宣称尺寸图已补齐。

## 标题比例

先保存用户所指基准（版本/图位/原字号或截图）。以“第一版小25%”为例，主标题目标为原来的0.75倍；小点使用独立层级，不跟着缩成不可读的角落说明。跨画幅比较时按相同显示尺寸评估；不能保证图像模型精确输出某个字号点数。调整后实际放大检查文字、语法、换行、边界和手机辨识度。

## 真实印花先于通用母版承诺

先看选品后的真实图案或有代表性的样本，判断题材、饱和度、画面密度、文字可读性和受众是否与场景一致。风格偏离时优先调整对应场景或分模板族；共用材质、版型、尺寸无需随之全部重做。不得承诺一个简约咖啡/办公场景母版覆盖所有街头、儿童、卡通、节庆或高饱和图案。

正式印花颜色、构图、透明边界及设计留白均受保护；换衣色不自动授权换印花颜色。“示例图案”和真实可售颜色组合明确区分。

## 交付与总览

一张3:4独立商品图应有完整场景、信息和排版。四宫格分镜板不是四张独立轮播。首套按约定先给独立图，再给可读总览。

仅生成总览时读取现有成图，保持比例、完整边界与编号，使用布局工具拼接，避免生成模型重绘导致服装、印花、文字或数值变动。标题/标签可在图外标注审核用途。明确当前采用版本，未批准或已作废候选不得混入当前总览。
