# PSD 产品：白胚审核与真实换印花验收

适用于本产品的新建或修改 PSD 轮播流程；仅拼接已有批准图片、非 PSD 产品或用户明确缩小的任务范围不触发额外制作。白胚指未印花的真实产品底色，不要求所有产品变成白色。保留各产品原有图数、规格、结构及交付规则。

## 白胚阶段同时提供实套效果

1. 自动准备四种适合当前产品、买家和主题的真实审核印花：A 透明底纯文字、B 透明底纯图案、C 透明底图文结合、D 满版图文结合。前三种保留透明背景及设计镂空；第四种覆盖真实可印区域。已有适用且可用的素材可复用；缺少类型时生成原创审核样稿，不把技术色块或网格当作缺失类型，也不将样稿虚构为已批准销售 SKU。
2. 沿用同一套白胚场景，四种印花分别实际替换完整 N 图轮播，内部检查每个可见印花实例。固定背面等 0 实例图可以保持相同；N 由当前产品声明确定。不能只验证主图，也不能逐款重新生成整个场景来冒充 PSD 换图。
3. 发给用户的白胚审核包为：**完整白胚轮播图 + 一张四款主图拼在一起的 2×2 四宫格总览**。四格分别是 A/B/C/D 的同一主图位实套效果，标明类型；不是四张四宫格，不是某一印花的四个图位。多底色组合主图保持该产品已定的组合，不能因此漏换实例。
4. 每次发送修订后的轮播审核时，一起附上当前版本的四款主图四宫格。底图、印花或映射未变的成果可复用，仅重做受影响项；不能展示旧版本实套效果来对应新版白胚。

白胚阶段可使用临时印花映射完成预览，不强迫提前交付最终 PSD，也不新增等待确认关卡。若工具或素材确实受阻，明确标记缺失的实套结果及未验收项，不能把只有白胚的阶段写成完整审核已通过。审核样稿不改变用户指定销售图案或冻结版本；仅换指定图案时按授权范围执行。

## 先核对输入，再判断覆盖

- 记录原稿像素、实际 PPI、透明通道、完整画布边界、有效主体边界，以及适配入口与 mode/fit。完整画布、图层可见内容 bounds、强可见主体不是同一个范围。
- 弱透明杂点可能让 alpha 边界接近整幅画布，但可见主体仍有大圈空白；不能仅凭非零 alpha 包围盒认定满版已顶边。区分真实柔边、阴影、刻意留白与杂点，保留原稿并记录任何清理或标准套图源的生成方式。
- 满版图检查是否实际铺到可印边界；透明文字、图案与图文保留设计负空间，不要求涂满产品。白色像素不等于透明；不自动去白、拉伸、裁掉重要文字或圆形边饰。
- 不把某个徽章的 alpha 阈值、裁圆、强制拉圆或放大比例推广到所有产品。按实际形状和设计意图选择规范化方式，匹配真实母稿像素与 PPI；不只匹配长宽比。

## 几何、边缘与光影必须分开验收

- 每个印花面以实际产品平面、曲面和相机关系建立映射。斜视检查近远边、长短轴、中心、圆形边饰和文字基线；布料按需要保留褶皱与遮挡。仅缩放加旋转不能证明透视正确，变换坐标前后相同只证明替换稳定。
- 蒙版贴合真实可印边界；不能内缩容错留下白圈，也不能为了盖白边覆盖金属、孔洞、倒角、手指或其他不可印区。先定位是源图留白、适配方式、映射还是蒙版问题，修复对应项，不靠随意放大掩盖。
- 用深色满版实际样稿辅助检查边缘，必要时临时关闭独立高光/阴影，区分漏出的底板与真实树脂反光。检查后恢复并验证光影；换图后仍需呈现实际材质的高光、阴影、厚度及遮挡。不要将图案自带浮雕错当真实结构，或按参考图臆造材料。
- 放大检查每一图位及每个拼图格、多色产品、局部特写的全部实例；同时在正常浏览尺寸检查比例、贴合和清晰度。场景应匹配实际买家用途与图案主题，不将单款宗教或其他主题强加给所有产品。

## 最终 PSD 与实际入口验收

1. 重开已保存的最终 PSD，检查共享母稿、嵌入素材、所有印花实例、蒙版和独立光影。四种真实样稿分别导出完整 N 图；用户提供过暴露问题的边饰、圆形或文字原稿时，将它追加为回归样本。纯色、条纹、网格等压力图只能补充，不能替代四类真实印花。
2. 使用用户实际指定或最终交付的换图 JSX/入口实跑。记录脚本名称、版本/哈希、实际参数、输入原稿、规范化输入（如有）、输出和日志。自写辅助入口成功，不能证明另一份用户 JSX 兼容；需要规范化输入时明确交付该方式，不宣称未经处理的任意原稿直接可用。
3. 核对所有实例更新、0 实例固定图不变、源像素/PPI、受保护像素及固定图文；检查满版完整覆盖、透明处无旧图或白方块、透视和光影。脚本无报错、图数正确、哈希不变或坐标检查通过，均不能单独替代这些视觉证据。
4. 最终 PSD 必须自包含。隔离测试要使原素材及辅助文件真正不可访问；只复制到新目录而原路径仍可读不算严格隔离。允许明确交付的新印花和脚本作为输入，不能依赖未交付的链接素材或原电脑路径。重开、换图并完整导出后再验证；没有第二台电脑实测就只报告隔离测试范围。
5. 分别记录结构/脚本运行、逐图视觉、迁移隔离、用户批准或委托状态。未执行或失败项标为未验证，修复后重测受影响项，不把技术通过写成视觉或用户批准。保存原稿、适配记录、实际输出与检查证据；公开 skill 仅保留通用规则，不能带入客户素材和私人路径。

## 最低回归情境

- 白胚阶段没有用户印花：自动补齐 A/B/C/D，白胚 N 图配一张主图 2×2；不要求提前交付最终 PSD。
- 透明图带柔边/杂点、满版带边饰：分别验证设计负空间与有效主体覆盖，不能统一按 alpha 外框缩放。
- 斜视佩戴/手持/多宫格：逐实例检查透视与遮挡；坐标未变不能直接判通过。
- 用户指定外部 JSX：按该入口和实际适配参数运行，不能用其他脚本结果代替。
- 只拼已有批准总览或非 PSD 产品：不额外生成四套；不修改冻结文件。
