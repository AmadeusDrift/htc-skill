# 通用／节日双线路

## 先分路线，再分主图用途

规划中显式记录 `route: general | holiday`、`theme`、`hero_usage: scene-hero | platform-main`，同时记录渠道/站点、性别/版型、真实衣色、语言、图数、比例、阶段和已批准参考。这些是规划字段，不是本技能自带的可执行配置接口。

| 判断 | 执行 |
|---|---|
| 日常、全年、通用；未指定节日 | general，theme=everyday |
| 圣诞、Christmas、节庆主题 | holiday，theme=Christmas或实际节日 |
| 同时要男女×通用/圣诞四套 | 建四条独立任务记录；先做用户指定首套，按授权范围推进 |
| 仅参考圣诞款的材质/版型做日常图 | general；只借用指定结构，不继承圣诞装饰和文案 |
| 用户所说“主图”指场景封面 | scene-hero；无附加文案 |
| 当前渠道要求上传MAIN白底 | platform-main；节日表现转入副图/场景封面，不把场景图宣称为合规MAIN |

路线、主题、图数及阶段按明确用户选择；平台合规声明以核实的渠道规则为准。主题已清楚不再让用户重选；未指定节日采用通用路线，简述假设即可。若渠道规则影响上线，核实当前站点和类目，记录来源；不从“亚马逊”三个字推断低价商城具体规则。

## 通用路线 general

以全年可用的居家、窗边、通勤、工作室、周末户外等真实情境为候选；无节日树、节庆灯饰和季节口号。真实图案的色彩、题材和受众先于母版通用性承诺：高饱和卡通、街头、极简文字可按需要分模板族。人物、衣色与产品事实保持一致，场景和动作有差异。沿用用户批准的图数和顺序；没有指定时提出可审核方案，不把八图示例当硬性要求。

## 节日路线 holiday（圣诞示例）

节日气氛主要由环境、光线和自然活动承担；印花始终为独立可替换资产，不能把圣诞树/字样烘焙在服装底图中。暖灯、深绿、酒红、少量金色可作为候选，真实服装及正式印花颜色不为配色而修改。其他节日重新按其文化和使用情境规划，不能机械套圣诞装饰。

场景可选壁炉客厅、树旁布置、窗边日光、门厅出行、聚会交流、礼物桌旁等；整套有至少三个明显不同的情境（完整场景套图适用），而非同一圣诞树背景换道具。避免满屏红绿、过多灯点和巨型前景装饰抢走衣服。礼盒、围巾、装饰物仅为情境道具，不暗示购买包含这些物品，也不暗示T恤适合低温保暖。

### 七图信息安排

用户要七张时，优先用以下职责覆盖；可按已批准顺序调整。卖点不足以支撑额外功能图时，补有差异的漂亮场景，不编造功能。

| 图位 | 信息职责 | 构图/印花要求 |
|---|---|---|
| 1 | 无叠字主图/场景封面 | 服装与胸口印花为视觉中心；用途服从渠道 |
| 2 | 材质/可信卖点 | 布料近景，褶皱与纹理清楚；成分按资料，取景可避印区 |
| 3 | 领口、袖口、下摆/版型 | 批准的一张组合细节图，不擅自拆成多图 |
| 4 | 印花展示/近景 | 可见正式图案接入共享母稿，保持比例、文字和边缘 |
| 5 | 尺寸/量法 | 真实可售范围、列对应及单位；缺数据仅做明确占位 |
| 6 | 行走/出行情境 | 自然动作、胸前可映射，不牺牲后续换图 |
| 7 | 节日生活情境 | 与1、6区分地点、角度、姿势、视线和表情 |

“圣诞七图”不能退化为七张人物场景。材质、结构、尺寸和印花信息都要覆盖；可合并信息，不能悄悄删掉必要图位。尺寸资料未提供时明确待补，不拿示例数字填满。尺码、成分和材质外观依[资料与尺码](facts-and-sizing.md)，不把某次订单的牛奶丝、棉涤比例、圆领或S–3XL写为所有产品事实。

## 一条可执行示例

用户：男款圣诞、七张、3:4、先预览，尺码后补。
记录：route=holiday；theme=Christmas；hero_usage按已确认渠道；gender=men；count=7；aspect=3:4；stage=preview；尺寸状态=pending。
先规划七张信息任务及三种情境，读取服装和示例印花，生成可复用的无印花清洁场景；在授权预览范围内通过临时映射叠入印花形成独立审核图，尺寸图只交占位。主图不叠字，材质不补虚构性能；不把未要求的女款/通用三套和完整PSD当作已获授权。用户授权PSD后再完成共享源、保存回归和交付验收。连续制作已经获授权时，无需人为新增“白胚审核”关卡。
