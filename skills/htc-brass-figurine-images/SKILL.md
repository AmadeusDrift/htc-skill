# 黄铜雕像生图

围绕用户提供的每一款黄铜雕像，制作完整七图轮播图与对应英文标题、五点和产品描述。保留 HTC 已确认的视觉策划、文案与交付流程；每款依据自身主体、姿态、配件、质感、尺寸和使用环境重新设计，不把绅士狗的造型、文字或场景套到其他款式。无需 POD 印花或 PSD 换图流程。

## 1. 整理输入与商品事实

读取用户的产品实拍、尺寸图、供应商资料和明确指定的参考；区分真实产品、视觉参考和待确认事实。记录款式主体、正反已见结构、表情姿态、随身物件、可见材质颜色与表面细节、尺寸及单位。用户已明确的事实采用；材质成分、重量、工艺、配件、包装和尺寸来源不清时标记待确认，不凭图片编造。只在缺项影响当前工作时问必要问题，独立部分继续。

识别用户本次需要首套完整图文、指定图位修改或已有图片组合。用户说已定稿、不要再改时，保持已确认画面和文案，仅做授权调整与交付；未经请求不重新设计。

## 2. 规划七图

从实物确定买家关注点、视觉焦点、真实使用方式和信息缺口，先计划每图的任务、场景、镜头、产品大小、英文文案与事实依据。以下是已确认的首套组织方式，具体图像随产品变化：

1. **场景主图**：突出完整产品、清楚识别款式，默认无额外文字；平台有特殊主图要求时按适用规则处理。
2. **造型特点**：完整产品结合此款最有辨识度的造型或重点细节，短标题和必要说明。
3. **场景或特点**：根据本款产品选择适合的场景或视觉重点，提供与其他图不同的信息。
4. **细节图**：放大真实可见的表情、纹理、配件或造型；适合时做多宫格及对应短说明。
5. **尺寸图**：依据已确认尺寸制作可读标尺，厘米与英寸同时展示；厘米除以 2.54，换算值保留两位小数。只标有依据的维度，标尺对准实际测量边界；未知维度不补造。
6. **使用场景**：根据商品合理展示桌面、书架或其他适用环境，与主图及第三图有明确区别。
7. **尺度与质感**：用合适的手持、参照物或其他方式展示真实大小和材质；参照比例需与已知尺寸一致，手和参照物不能遮挡关键造型。

图位中的场景、构图、文字位置、细节数量和标题均按实际雕像自由适配；不为了凑图虚构功能、配件或结构。用户指定的图位、数量或范围优先。参考用户已批准的首套方向：产品主体清晰、偏真实摄影、暖中性色调和简洁排版；它是方向而非固定模板。

## 3. 制作并核验

以真实产品图为主要视觉依据，逐图使用可用图片生成工具完成画面、正式文字和排版；在提示中明确必须保留该款独有的轮廓、姿态、五官、服饰、配件、色泽与纹理。不同视角仅在已有证据支持时作为真实展示，不把生成的背面当实拍事实；场景道具不暗示随货附赠。

逐张检查主体是否被改变或漏件、场景中尺寸是否可信、金属质感是否接近实物、英文和数字是否正确、文字在手机预览是否可读，以及七图是否有信息差异。放大检查尺寸引线是否对应实际测量位置和手持参照比例；若依据不足则说明并保留待确认，不把生成图当证明。存在错字、结构或参数错误时修正后再交，不用文件存在证明视觉通过。平台主图、类目与站点要求在正式上架前核实；场景主图不自动等于平台合规。

## 4. 商品文案

默认输出英文标题、恰好五条 bullets、一个纯文本产品描述，附中文信息及必要译文。标题沿用 HTC 格式：**款式描述词或词组 + 固定产品名称**，如同一系列用实际款式词替换前缀，固定产品名称保持一致；非印花雕像按主体款式组织，不虚构印花。不同款式的五点与描述在事实确实共通时共享，不把只适用于一款的细节写成整个系列通用属性；资料不足不凑卖点。

文案只使用有依据的材质、结构、尺寸、装饰用途等事实，五点从不同角度写，首字母大写，避免全大写、表情、促销或无依据承诺，末尾不加标点。不强制送礼或节日词，不保证零侵权风险。记录标题、每条五点和描述长度及所用限制来源。

适用站点、产品类型的官方字段限制优先；未取得适用官方数值时使用用户兜底：标题 125 字符、每条五点 500 字符、整段描述 500 字符，均含空格，并明确这是用户兜底而非已核实的官方限制。若官方采用字节等其他单位，则按实际单位检查；明确缺少站点或类目时的核验范围。

## 5. 审核与交付

首次交付完整七张成图、七图总览和对应文案，说明图片编号、产品事实缺项、平台规则核验状态及仍待处理的视觉问题。每款按自己的产品/SKU目录保存，提供直达文件链接；原始参考和工作素材分开保存。默认不打包，不额外制作 PSD；总览或指定图位组合直接使用已有成图。用户批准后保留批准版本，之后仅修改明确指定的内容。
