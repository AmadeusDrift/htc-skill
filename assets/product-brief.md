# 产品输入表

接收现有截图、链接、文件和聊天确认，由AI整理；不要求先填完整表。与当前任务无关的未知项不阻塞全部工作。

| 项目 | 需要整理的内容 |
|---|---|
| 阶段与授权 | 新商品／重做首套／已有批准母版只换图／只要总览打包；是否本次取消中间暂停 |
| 实物 | 稳定编号、真实销售物、外观／结构／开合／参数／尺寸截图，旧印花是否仅展示 |
| 已确认事实 | 参数与单位、来源或用户原话；已确认的尺寸不再列待核实 |
| 未知事实 | 实际加工范围、工艺、数量、包装、配件、倍率、性能等，不据画面推断 |
| 参考 | 用户直接指定的Amazon／Temu链接或截图；实物与参考事实分开 |
| 买家与购买理由 | 目标买家、使用场合、图案情绪价值、购买疑虑、适合表达的卖点 |
| 第一套视觉 | 场景／光线／配色、构图、产品与文字留白、字体层级、正式英文及中文意思；图片生成工具完成全部图文，错误回生成工具修改，PS不改字 |
| 图案 | 用户指定ID、独立原稿、样式与比例、透明通道、来源／授权；模糊修复是否授权 |
| 每套图位 | 固定七图：场景主图／产品卖点及完整功能／场景或功能／产品细节／三维尺寸／使用场景／手持质感 |
| 颜色矩阵 | 印花ID×实际可售底板颜色、主配色；主配色01同印花多底色组合，其他颜色子体01单产品 |
| 卖点与表面效果 | 底板卖点依据已确认事实；不强制水晶标工艺文案。哑光／亮面由用户团队自行判断，不设确认关卡 |
| 产品细节 | 单特写或多宫格、局部位置、每格简洁描述；全部收在04一张图片里 |
| 三维尺寸 | 宽度、高度、厚度、来源单位与厘米／英寸双单位、各维度来源与测量位置；厘米与英寸互换，保留原值并同时标注两单位；尺寸图仅引线和数值；缺项待补 |
| 贴标方式 | 仓库员工贴好后交付，不制作DIY粘贴指引图、示意图或教程视频 |
| 母版 | 源画布、可换区／禁区、蒙版／前景／透视／光影、固定底图中已定稿文字、全部可见印花对象映射与工具支持；PS只制作印花PSD |
| 复用与批准 | 共用结构／尺寸图路径、首套版本、approved或delegated依据、冻结SHA256 |
| 输出 | 一个印花一个SKU，SKU文件夹含完整七图、印花.png、文案.txt、总览.jpg；通用图可重复，不另复制交付目录，默认不打包 |
| 文件路径 | PSD直接放产品根目录；原始资料放工作参考，候选／底图／测试图放工作资料/中间产物；生产清单与相对路径记录放工作资料；旧图及PSD不迁移 |
| 商城文案 | 站点、类目、语言、固定标题模板与可变印花词组、标题／五点／产品描述、官方字段限制与核对日期；政策未核实不称已通过 |

用户提供无印花产品时，不把供应商展示款图案当产品材质。修复模糊截图是一次性独立印花准备，不授权后续逐款重绘产品场景；补绘不等于恢复原始像素。批准后只换图交付，不额外优化。

补充：每款满版／镂空类别及有效图案边界；每个实例的真实可印边界、精细蒙版、出血及边缘检查；标题依产品占比和留白动态调整，同套字体统一。

03由 Codex 根据产品特点与整套图的信息需要，自行判断采用场景图还是功能图，不要求用户另选路线。作图逻辑与其他场景图、功能图一致，包括场景、构图、文案、排版、事实依据及制作流程；与01、02、06避免重复；取消水晶标卖点图的四条路线选择，不再要求固定水晶标标题及五条工艺卖点。哑光还是亮面由用户团队自行判断，不设选择或确认关卡，也不默认制作材质对比图。
