# 产品输入表

接收现有截图、链接、文件和聊天确认，由AI整理；不要求先填完整表。与当前任务无关的未知项不阻塞全部工作。

| 项目 | 需要整理的内容 |
|---|---|
| 阶段与授权 | 新商品／重做首套／已有批准母版只换图／只要总览打包；是否本次取消中间暂停 |
| 实物 | 稳定编号、真实销售物、外观／结构／开合／参数／尺寸截图，旧印花是否仅展示 |
| 已确认事实 | 参数与单位、来源或用户原话；已确认的尺寸不再列待核实 |
| 未知事实 | 实际加工范围、工艺、数量、包装、配件、倍率、性能等，不据画面推断 |
| 参考 | 用户直接指定的Amazon／Temu链接或截图；实物与参考事实分开 |
| 买家与购买理由 | 目标买家、使用场合、图案情绪价值、购买疑虑、适合表达的卖点 |
| 第一套视觉 | 场景／光线／配色、构图、产品与文字留白、字体层级、正式英文及中文意思 |
| 图案 | 用户指定ID、独立原稿、样式与比例、透明通道、来源／授权；模糊修复是否授权 |
| 每套图位 | 默认每款七图；角色按商品规划，购买问题与信息增量明确 |
| 母版 | 源画布、可换区／禁区、蒙版／前景／透视／光影、可编辑文字与工具支持 |
| 复用与批准 | 共用结构／尺寸图路径、首套版本、approved或delegated依据、冻结SHA256 |
| 输出 | N种印花=N套完整七图、每套总览；只在要求时制作指定图位四宫格／分包 |
| 商城文案 | 站点、类目、语言、标题与五点、规则来源；政策未核实不称已通过 |

用户提供无印花产品时，不把供应商展示款图案当产品材质。修复模糊截图是一次性独立印花准备，不授权后续逐款重绘产品场景；补绘不等于恢复原始像素。批准后只换图交付，不额外优化。
